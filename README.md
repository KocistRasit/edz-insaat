# EDZ İnşaat & Gayrimenkul - Web Sitesi Önizleme (GitHub Pages)

Bu depo **www.edzinsaat.com.tr** için hazırlanan kurumsal web sitesi önizleme sürümünü içerir.

## GitHub Pages Üzerinde Yayınlama Adımları
1. GitHub hesabınızda yeni bir **Public** depo (repository) oluşturun (örneğin: `edz-insaat`).
2. Bu klasördeki `index.html` dosyasını deponun ana dizinine yükleyin (**Add file > Upload files**).
3. Depo menüsünden **Settings > Pages** sekmesine girin.
4. **Build and deployment > Branch** altında `main` dalını seçip **Save** butonuna basın.
5. 1-2 dakika içinde siteniz `https://kullaniciadiniz.github.io/edz-insaat/` adresinde yayına girecektir.
